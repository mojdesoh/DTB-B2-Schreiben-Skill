# DTB B2 Schreiben Review

Use this skill whenever the user submits a German text written as practice for the **Deutsch-Test für den Beruf B2 (DTB B2 / telc B2 Beruf)** and wants it graded or corrected. It covers the two free-writing tasks:

- **Lesen und Schreiben Teil 2** (item 21) — reply email to a customer, following the Teamleitung's instructions
- **Schreiben** (item 58) — Forumsbeitrag in the company forum, Thema A or B

Out of scope: Telefonnotiz (Hören und Schreiben) and Sprachbausteine. For DTZ B1 texts, use the DTZ skill instead.

Grade at **real examiner level** — do not inflate. Write explanations in **English**, with all examples, corrections and Redemittel in **German**.

---

## 1. Inputs — check before grading

Required with every submission:

1. **The user's text.**
2. **The task prompt:**
   - Email: the customer's email **and** the Teamleitung's note (its instructions are the main checklist).
   - Forum post: the topic (A or B) with its full wording.

If the task prompt is missing, ask for it in one short question before grading. If the user cannot provide it, grade anyway, but mark the task-completion score as **provisional** and check only the generic structure.

Optional: time taken (exam: 20 min for email incl. 2 MC items; ~25 min of the 35-min block for the forum post), whether it was handwritten.

## 2. Official scoring (telc DTB B2)

Writing (Schreiben) = 60 points in total, of which these two texts carry **48**:

| Component | Max | Steps |
|---|---|---|
| Email — Kriterium I (Kommunikative Aufgabenbewältigung) | 7 | A 7 / B 5 / C 3 / D 0 |
| Forum post — Kriterium I | 14 | A 14 / B 10.5 / C 5.5 / D 0 |
| II Kommunikative Gestaltung (both texts together) | 9 | B2 gut 9 / B2 7 / B1 3.5 / below 0 |
| III Formale Richtigkeit (both texts together) | 9 | 9 / 7 / 3.5 / 0 |
| IV Spektrum sprachlicher Mittel (both texts together) | 9 | 9 / 7 / 3.5 / 0 |

(The remaining 12 Writing points come from the Telefonnotiz (6) and Sprachbausteine (6) — not graded here.)

- In the real exam, II–IV are judged once across **both** texts. When only one text is submitted, judge II–IV on that text alone and say so.
- **Thema verfehlt** (text does not address the task): Kriterium I = 0 for that text. Check this first.
- Passing logic for context: each skill needs ≥ 36/60 (one skill may be compensated at 24–35), and ≥ 144/240 overall. For a single text, report a percentage of its achievable points and compare to the 60% line.

### Kriterium I — level descriptors (official wording, condensed)

- **A:** Task fully adequate for the workplace situation and level; addresses the reader appropriately with the right degree of formality.
- **B:** Mostly adequate; reader mostly addressed appropriately.
- **C:** Only partly adequate; register not always appropriate.
- **D:** Not adequate; register only partly appropriate.

Practical mapping:
- **A** — every instruction covered fully and plausibly, structure complete, register consistent.
- **B** — one instruction thin or one structural/register lapse.
- **C** — one instruction missing, or several thin, or noticeable register problems.
- **D** — most instructions missing or the text barely fits the situation.

### Criteria II–IV — level descriptors (official wording, condensed)

**II Kommunikative Gestaltung**
- B2 gut: clear, coherent workplace text; varied connectors used purposefully to show relationships.
- B2: largely clear and coherent; a limited range of connectors.
- B1: simple coherent text; a linear chain of short elements.
- Below: simple text with only the most common connectors.

**III Formale Richtigkeit**
- B2 gut: simple and most complex structures largely correct; occasional errors in complex ones; spelling/punctuation largely correct.
- B2: simple and some complex structures largely correct; errors in complex ones; spelling sufficiently correct.
- B1: common forms sufficiently correct; errors occur but meaning stays clear.
- Below: systematic elementary errors.

**IV Spektrum sprachlicher Mittel**
- B2 gut: broad range, frequent variation, some complex sentence structures.
- B2: sufficiently broad range, variation, some complex structures; gaps may cause paraphrasing.
- B1: enough to get by; mostly simple sentence structures.
- Below: short common expressions, simple patterns.

### This framework's additional rules (not official — state them as such)

- **Fewer than 4 correctly used B2 grammar points** (section 4) → IV is capped at **B2 (7)**; with 0–1 → capped at **B1 (3.5)**.
- **Fewer than 6 B2 vocabulary items** (section 5) → IV cannot be **B2 gut**.
- **Basic words repeated 3+ times** → mention under IV and lower it one step if the text feels repetitive overall.

## 3. Task completion checklists (Kriterium I)

### 3a. Email to the customer (item 21)

**Primary checklist = the Teamleitung's instructions.** List each instruction from the note (e.g. "be polite", "name the reason", "explain how we'll solve it in future", "offer a meeting", "don't promise a refund") and mark it ✅ fully / ⚠️ partly / ❌ missing. The note always overrides the generic structure below: if it says not to offer a discount, offering one is an error.

**Generic structure for a complaint reply** (adapt for other email types such as Anfrage, Terminänderung, Rückfrage):

1. **Betreff** — specific, e.g. *Ihre Beschwerde vom 12.03. – Reinigung der Konferenzräume*
2. **Anrede** — correct formal salutation with the name (*Sehr geehrter Herr Stemmler,* — comma, lowercase start of next line)
3. **Thanks** for the message (*Vielen Dank für Ihre E-Mail vom …*)
4. **Apology / regret**, sincere and specific (*Es tut uns sehr leid, dass …*)
5. **Restate the problem(s)** — address **each** point the customer raised, not only the main one
6. **Plausible cause** — only if the note allows it. The cause must:
   - make sense for the situation (e.g. a cleaning firm → staff shortage, new staff not yet trained; not "our server crashed")
   - not contradict facts in the prompt (timeframe, people, service)
   - not blame the customer
7. **Immediate solution** — what has already been done / will be done now
8. **Future prevention** — concrete and realistic (training, checklist, fixed contact person, quality control)
9. **Goodwill gesture** — discount, credit note, free extra service — proportionate to the problem, and only if consistent with the note
10. **Deadline** — if the customer set one, the reply respects it
11. **Closing** — offer to be available for questions; hope to keep the customer (*Wir hoffen, Sie weiterhin zu unseren zufriedenen Kunden zählen zu dürfen.*)
12. **Grußformel + name + role/company** (*Mit freundlichen Grüßen* — no comma after it in German business emails)

**Register:** formal Sie throughout; consistent capitalisation of *Sie/Ihr/Ihnen*; no colloquial words.

**Plausibility check:** read the email as the customer would. Flag anything illogical, contradictory, over-promised ("this will never happen again" is weaker than a concrete measure) or vague ("we will fix it").

### 3b. Forumsbeitrag (item 58)

The task always says: give your opinion, give reasons, give suitable examples, divide the text into sensible paragraphs.

1. **Anrede** to colleagues — *Liebe Kolleginnen und Kollegen,* / *Hallo zusammen,*
2. **Introduction** — name the topic / what is planned (in own words, not copied from the prompt)
3. **Clear position** — the reader knows the writer's stance early
4. **2–3 reasons**, each supported by a **concrete workplace example**
5. **Other side** acknowledged and answered (*Zwar …, aber …* / *Einerseits …, andererseits …*)
6. **Conclusion** — summary and/or suggestion or compromise
7. **Closing** — greeting and name (*Viele Grüße, …*)

Checks:
- All aspects of the prompt addressed (e.g. Thema B "Kleiderordnung" has two parts: uniform clothing **and** private cleaning costs — both need a response)
- **Visible paragraphs** (a block of text loses points under Kriterium I and II)
- Register consistent: Du or Sie are both acceptable for colleagues, but never mixed
- Examples are specific and believable, not generic

## 4. Grammar requirement: at least 4 B2 grammar points per text

Find every use of these structures. **A point counts only if used correctly.** Attempted but faulty uses are listed as errors with a correction and do not count. Each point counts once per text, however often it appears.

| # | Grammar point | What to look for | Example |
|---|---|---|---|
| 1 | Verb und Ergänzungen | Correct case for verb complements, especially Dativ + Akkusativ | *Wir bieten Ihnen einen Rabatt an.* |
| 2 | Wortstellung (TeKaMoLo) | Several adverbials in correct order | *Wir reinigen ab sofort täglich gründlich alle Räume.* |
| 3 | Kausale Konnektoren | weil, da, denn, deshalb, daher, nämlich | *Da zwei Mitarbeiter krank waren, …* |
| 4 | Trennbare/untrennbare Vorsilben | Correct separation and Partizip II (*mit Kunden umgehen* vs. *ein Problem umgehen*; *übernehmen* → *übernommen*) | *Wir übernehmen die Kosten.* / *Wir stellen neues Personal ein.* |
| 5 | Obligatorisches „es“ | Fixed expressions | *Ich finde es wichtig, dass …* / *Es handelt sich um …* |
| 6 | Verwendung von „es“ | Platzhalter, es gibt, impersonal subject | *Es ist uns wichtig, Sie zufriedenzustellen.* |
| 7 | Infinitivsätze mit „zu“ | um … zu, ohne … zu, statt … zu, versuchen/planen … zu | *Wir haben beschlossen, die Abläufe zu ändern.* |
| 8 | Adjektivdeklination nach Nullartikel | Endings with no article | *mit freundlichen Grüßen*, *aufgrund kurzfristiger Ausfälle* |
| 9 | Nebensätze der Folge | so …, dass / sodass | *Es fehlte Personal, sodass einige Räume nicht gereinigt wurden.* |
| 10 | Modale Nebensätze | indem, dadurch dass, ohne dass | *Wir verbessern die Qualität, indem wir Checklisten einführen.* |
| 11 | Partizipialkonstruktionen | Partizip I/II as extended attribute | *die entstandenen Unannehmlichkeiten*, *das neu eingestellte Personal* |
| 12 | Weiterführende Nebensätze | was / wo(r)+Präposition referring to whole clause | *Wir gewähren Ihnen 10 % Rabatt, was hoffentlich …* |
| 13 | Präpositionale Angaben | aufgrund, wegen, trotz, infolge, während + Genitiv | *Aufgrund eines Personalengpasses …* |
| 14 | Nomen-Verb-Verbindungen | see section 5 list | *Maßnahmen ergreifen* |
| 15 | Umschreibung von Modalverben | sein + zu, lassen sich, haben + zu, -bar/-lich | *Das Problem lässt sich schnell lösen.* / *Die Räume sind täglich zu reinigen.* |
| 16 | Verben/Nomen/Adjektive mit Präpositionen | Correct preposition and case | *sich entschuldigen für*, *zufrieden mit*, *Interesse an* |
| 17 | Relativsätze im Genitiv | dessen / deren | *der Kunde, dessen Auftrag …* |
| 18 | Irreale Bedingungen/Wünsche (Vergangenheit) | hätte/wäre + Partizip II | *Hätten wir früher reagiert, wäre das nicht passiert.* |
| 19 | Indirekte Rede (Konjunktiv I/II) | Reporting speech | *Sie schreiben, die Räume seien nicht ordentlich gewesen.* |

Quality notes:
- Points 1, 2, 4 and 6 appear in almost every text. Count them only when used at a clearly B2 level (e.g. two objects with correct cases, three adverbials in correct order, a separable verb in a subordinate clause or a Partizip II), and say so.
- Recommend structures that fit naturally: 11, 13, 14 and 15 suit formal emails; 9, 10, 12 and 18 suit forum posts.
- When fewer than 4 points count, suggest 1–2 sentences from the user's own text rewritten with a missing structure.

## 5. Vocabulary requirement

Targets per text:
- **At least 6 distinct B2-level items** (Nomen-Verb-Verbindungen, Redemittel, B2 connectors, workplace nouns)
- **Basic words** — *machen, gut, schlecht, Problem, sagen, sehr, viel, Sache, Ding, haben* — not repeated more than twice; suggest an alternative for each overuse
- Register-appropriate (no *okay*, *super*, *kein Ding* in the email)

Count and list the B2 items found. Flag misused ones (wrong collocation, wrong preposition).

### Nomen-Verb-Verbindungen
Maßnahmen ergreifen · eine Entscheidung treffen · Verantwortung übernehmen · zur Verfügung stehen/stellen · in Anspruch nehmen · Rücksicht nehmen auf · Kritik üben an · einen Beitrag leisten zu · zum Ausdruck bringen · in Frage kommen · in Kauf nehmen · Bescheid geben · in Kontakt treten mit · zur Kenntnis nehmen · eine Rolle spielen · Bezug nehmen auf · einen Vorschlag machen · eine Lösung finden · Einfluss nehmen auf · Wert legen auf

### Redemittel — email (complaint reply)
- Vielen Dank für Ihre E-Mail vom … / Wir haben Ihre Nachricht erhalten und …
- Wir bedauern sehr, dass … / Es tut uns außerordentlich leid, dass …
- Bitte entschuldigen Sie die entstandenen Unannehmlichkeiten.
- Ihre Kritik ist berechtigt. / Wir nehmen Ihre Beschwerde sehr ernst.
- Der Grund dafür ist, dass … / Dies ist darauf zurückzuführen, dass …
- Wir haben bereits Maßnahmen ergriffen, um …
- Ab sofort / Künftig werden wir sicherstellen, dass …
- Als Zeichen unseres Entgegenkommens bieten wir Ihnen … an.
- Gern gewähren wir Ihnen einen Preisnachlass von … / eine Gutschrift über …
- Wir hoffen, Sie weiterhin zu unseren zufriedenen Kunden zählen zu dürfen.
- Für Rückfragen stehen wir Ihnen jederzeit gern zur Verfügung.

### Redemittel — forum post
- Ich möchte mich gern zum Thema „…“ äußern.
- Meiner Ansicht/Auffassung nach … / Ich bin der Meinung, dass …
- Ein wichtiges Argument für/gegen … ist, dass …
- Hinzu kommt, dass … / Darüber hinaus …
- Aus eigener Erfahrung weiß ich, dass … / Ein Beispiel dafür ist …
- Zwar …, aber … / Einerseits …, andererseits …
- Es lässt sich nicht leugnen, dass …
- Zusammenfassend lässt sich sagen, dass …
- Deshalb schlage ich vor, dass … / Ein möglicher Kompromiss wäre …
- Ich bin gespannt auf eure/Ihre Meinungen.

## 6. Error categories

Group every error into one category so patterns are visible:

- **Kasus** — wrong case after verb/preposition, wrong article
- **Endungen** — adjective/noun endings
- **Verbposition** — V2, verb-final in Nebensatz, separable prefix position
- **Verbform** — conjugation, Partizip II, Konjunktiv, Passiv
- **Präposition** — wrong preposition in a fixed combination
- **Wortwahl** — wrong word, wrong collocation, wrong register
- **Rechtschreibung** — spelling, capitalisation (Nomen, Sie/Ihnen)
- **Zeichensetzung** — commas before Nebensätze and Infinitivsätze, comma after Anrede

Name the 1–2 categories with the most errors as the user's current pattern.

---

## 7. Length guidance (unofficial)

There is no official word count. As a rough orientation: email ~120–150 words, forum post ~180–220 words. Mention length only if the text is clearly too short to cover the task, or so long it would not fit the time limit.

## 9. Principles

- **Be honest.** A B1 text is graded B1. Explain every deduction with a quote from the text.
- **Quote the user's own words**; never invent errors or credit structures that are not there.
- **Keep the text theirs** — minimal corrections in section 6, upgrades only in section 7.
- **Separate official rules from this framework's rules** (the 4-grammar-points rule, the 6-vocabulary rule, the length guidance).
- **Track progress.** If earlier rounds appear in the conversation or project, compare: which scores moved, and whether the main error pattern is still present. Always end with the progress line so the user can log it.
